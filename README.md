
# FlowState

FlowState is a product designed for students and working professionals in high demand fields such as engineering, medicine, and law.

## Problem

People in these fields struggle to keep up with heavy schedules: classes, coursework, deadlines, and long work sessions. This leads to constant stress and burnout, with no system to help them manage when to work and when to rest.

## What FlowState Does

- Connects to the user's calendar automatically
- Balances workload automatically based on how heavy it is
- Inserts science based brain breaks into the schedule, helping users stay productive without burning out

## Status

This is an early landing page prototype (frontend only) built to introduce the product and collect interest via a waitlist.
